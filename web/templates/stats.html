Prediction Strategy

Features (38 total)

  • Elo & Glicko-2 Ratings - Dual rating systems with time-decay K-factor
  • World Ranking - HLTV official ranking differential
  • Win Rate (30d / 90d) - Multi-window win rate tracking
  • SoS-Adjusted Win Rate - Strength-of-schedule weighted results
  • Tournament Momentum - Performance within current event
  • Recent Form (5/10) - Weighted recent match results
  • Head-to-Head - Historical matchup with reliability scaling
  • Map Win Rate + CT/T Sides - Map-specific side performance
  • Pistol Win Rate - Pistol round conversion rate
  • Map Pick Advantage - Map veto proxy (is this their pick?)
  • Player Metrics - Avg rating, star player, AWP presence, roster stability
  • Context - LAN/online, playoff, BO format, rest days

Model Architecture

Stacking Ensemble with 4 base models:

  • XGBoost - Gradient boosted trees with regularization
  • GradientBoosting - sklearn gradient boosting
  • LightGBM - Microsoft's fast gradient boosting
  • Logistic Regression - Linear baseline on scaled features

Meta-learner: Logistic Regression on OOF predictions. Calibration: Isotonic regression for probability calibration.

BO3/BO5 Simulation

Monte Carlo simulation (10,000 runs) with per-map probability estimation and map veto modeling.

Data Sources

  • HLTV.org (rankings, match results, player stats)
  • PandaScore API (historical matches, team metadata)
  • Custom Elo & Glicko-2 rating systems with time-decay
